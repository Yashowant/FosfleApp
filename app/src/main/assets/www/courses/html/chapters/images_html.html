A picture is worth a thousand words. Learn how to display images on your web pages and make them accessible to everyone using the HTML Image tag.

Section 01

What are HTML Images?

Images can improve the design and the appearance of a web page significantly. In HTML, images are not technically inserted into a web page; they are linked to web pages. The <img> tag creates a holding space for the referenced image.

The <img> tag is empty, meaning it contains attributes only, and does not have a closing tag.

⚠️
Empty Elements Unlike paragraphs <p>...</p> or links <a>...</a>, the image tag stands alone. You just write <img> and put all the necessary information inside the opening tag as attributes!
Section 02

The "src" Attribute

The required src attribute specifies the URL (web address) of the image. When a web page loads, it is the browser that gets the image from a web server and inserts it into the page.

ExampleHTML
<img src="https://images.unsplash.com/photo-1472214103451-9374bd1c798e?w=400&q=80">

Section 03

The "alt" Attribute

The required alt attribute provides an alternate text for an image, if the user for some reason cannot view it (because of slow connection, an error in the `src` attribute, or if the user uses a screen reader).

Why the Alt Attribute is Important
Reason Description
Accessibility Screen readers (used by visually impaired users) read the `alt` text aloud, allowing them to "hear" what the image shows.
Broken Links If the image file is deleted or spelled wrong, the browser will display the `alt` text in its place so users aren't confused.
SEO (Search Engines) Search engines like Google can't "see" images. They use the `alt` text to understand what the image is about and rank your page.
Broken Image ExampleHTML
<!-- Notice the spelling mistake in src! -->
<img src="wrong-name.jpg" alt="A girl with a jacket">
Browser Output
Section 04

Image Size - Width and Height

You can use the style attribute to specify the width and height of an image in pixels (px) or percentages (%). Alternatively, you can use the classic HTML width and height attributes.

✅
Best Practice: Use CSS! While HTML attributes (like width="500") work, it is highly recommended to use CSS (like style="width:500px;"). This ensures that standard style sheets don't accidentally ruin your image sizes.
Sizing ExampleHTML
<!-- Sizing with HTML Attributes -->
<img src="photo.jpg" alt="A car" width="500" height="600">

<!-- Sizing with CSS Style (Recommended) -->
<img src="photo.jpg" alt="A car" style="width:500px; height:600px;">
Section 05

Images as Links

Want an image that you can click to go somewhere else? Simple! Just put an <img> tag completely inside an <a> (anchor) tag.

Clickable Image ExampleHTML
<a href="https://google.com">
  <img src="logo.jpg" alt="Go to Google" style="width:100px;">
</a>

Chapter Summary

            

                Key takeaways from HTML Images
            

        

        

            

                

                
Use the HTML <img> element to define an image on a webpage.

            

            

                

                
Use the HTML src attribute to define the URL or file path of the image.

            

            

                

                
Use the HTML alt attribute to define an alternate text if the image cannot be displayed, which is vital for accessibility.
