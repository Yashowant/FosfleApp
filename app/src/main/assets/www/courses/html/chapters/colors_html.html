Section 01

What Are HTML Colors?

Every element on a webpage can have a color — text, backgrounds, borders, shadows. HTML colors are values that tell the browser exactly which shade to paint. You can specify them in several ways: by name, by hex code, by RGB, or by HSL.

💡
Did You Know? Modern browsers support over 16 million distinct colors using RGB notation — more shades than the human eye can distinguish.
Section 02

Named Colors

HTML recognizes 140 official color names. You can use words like red, blue, tomato, or cornflowerblue directly as values. They're great for quick prototyping and easy to remember.

ExampleHTML
<p style="color: tomato;">
  Fresh and bold
</p>
<p style="background-color: cornflowerblue;">
  Cool and calm
</p>

Hex Color Codes

A hex color is a six-digit code preceded by #. The first two digits control Red, the next two control Green, and the last two control Blue. Each pair ranges from 00 (none) to FF (full).

Section 05

HSL Colors

HSL stands for Hue, Saturation, and Lightness. It's the most intuitive format for humans — you think about the color wheel (hue), how vivid it is (saturation), and how light or dark it is (lightness).

Hue · 0°–360°

The color wheel position in degrees.

Saturation · 0%–100%

0% = grey. 100% = full vivid color.

Lightness · 0%–100%

0% = black. 50% = normal. 100% = white.

ExampleHTML
<p style="color: hsl(9, 100%, 64%);">
  Tomato — hsl(9°, vivid, mid)
</p>
<p style="color: hsl(220, 90%, 56%);">
  Royal Blue
</p>
Browser Output

Tomato — hsl(9°, vivid, mid)

Royal Blue

Section 06

Transparency with RGBA & HSLA

Adding an alpha channel makes a color transparent. In rgba() and hsla(), the last value is a number from 0 (fully transparent) to 1 (fully opaque).

rgba(52, 152, 219, 0.1) → rgba(52, 152, 219, 1.0)

ExampleHTML
/* Solid background */
<div style="background: rgba(52,152,219,1);">
  Fully opaque
</div>

/* Semi-transparent overlay */
<div style="background: rgba(52,152,219,0.3);">
  See-through
</div>
Browser Output
Fully opaque
See-through

Section 08

Color Properties in HTML & CSS

Color values are used with different CSS properties. The most common are color for text and background-color for backgrounds, but colors also work with borders, shadows, and outlines.

ExampleHTML
/* Text color */
<p style="color: #e74c3c;">Red text</p>

/* Background color */
<div style="background-color: #f39c12;">
  Orange bg
</div>

/* Border color */
<div style="border: 3px solid #8e44ad;">
  Purple border
</div>

Section 09

Color Format Comparison

The same color can be written in multiple formats. All four of the following produce identical results in the browser — choose whichever makes most sense for your project.

Format Example Best For Supports Transparency
Named tomato Quick prototyping ❌ No
HEX #FF6347 Design tools & brand colors ⚠️ HEX8 only
RGB rgb(255,99,71) Programmatic color mixing ❌ No
RGBA rgba(255,99,71,0.5) Overlays & transparent layers ✅ Yes
HSL hsl(9,100%,64%) Intuitive color adjustments ❌ No
HSLA hsla(9,100%,64%,0.7) Themed UI systems ✅ Yes
Section 10

Common Mistakes

🚫
Forgetting the # in hex codes Writing FF6347 instead of #FF6347 — the browser won't understand it.
🚫
Exceeding the range RGB values must be 0–255. Writing rgb(300, 0, 0) is invalid.
🚫
Misspelling named colors cornflowerblue is one word. Spaces and hyphens break named colors.
⚠️
Poor color contrast Light text on a light background — or dark text on dark — is unreadable and fails accessibility guidelines.
Section 11

Best Practices

✅
Tips for Beginners
  • Use hex codes when copying colors from design tools like Figma.
  • Use HSL when building themes — it's easy to lighten or darken by adjusting lightness alone.
  • Use RGBA for overlays, modals, and semi-transparent elements.
  • Always check color contrast for accessibility — aim for a contrast ratio of at least 4.5:1 for body text.
  • Keep a consistent color palette across your project by defining colors once in CSS variables.
Chapter Summary

Everything that stuck to the canvas

HTML colors can be written as named colors, hex codes, RGB, or HSL values.

Hex codes use six hexadecimal digits: two for red, two for green, two for blue.

RGB mixes red, green, and blue light using values from 0 to 255.

HSL is the most human-readable format — hue (angle), saturation (%), lightness (%).

Adding an alpha channel with rgba() or hsla() controls transparency (0–1).

The color property styles text; background-color fills backgrounds.

Always ensure sufficient color contrast for accessibility — especially between text and its background.
