HTML Editors

Write your first lines of code.

A simple text editor is all you need to learn HTML.

Learn HTML Using Notepad or TextEdit Web pages can be created and modified using professional HTML editors. However, for learning HTML, we recommend a simple text editor like Notepad (PC) or TextEdit (Mac). We believe that starting simple is the best way to grasp the fundamentals without getting distracted by complex software.

1 Open Notepad (PC) or TextEdit (Mac)

Windows:

Open the Start Screen (the window symbol at the bottom left on your screen). Type Notepad and hit Enter.

Mac:

Open Finder > Applications > TextEdit.

Important: You must set TextEdit to plain text. Go to Format > Make Plain Text.

2 Write Some HTML

Write or copy the following HTML code into your text editor:

index.html 
<!DOCTYPE html>
<html>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>

3 Save the HTML Page

Save the file on your computer. Select File > Save as in the Notepad menu.

Name the file index.html and set the encoding to UTF-8 (which is the preferred encoding for HTML files).

Tip: You can use either .htm or .html as a file extension. There is no difference, it is up to you.
Windows Users: Ensure "Save as type" is set to All Files (*.*). Otherwise, Notepad might save it as index.html.txt, which won't work!

4 View & Edit the HTML Page

Open the saved HTML file in your favorite browser (double-click on the file, or right-click and choose "Open with"). The result will look like this:

My First Heading

My first paragraph.

How to edit your file again: If you double-click your file, it will open in your browser, not your editor. To edit the code again, right-click the file, select Open with..., and choose Notepad or TextEdit. After making changes, save the file and simply refresh your browser to see the updates!

Ready for Modern Editors?

Once you are comfortable with the basics, we highly recommend downloading a modern code editor. They provide syntax highlighting, auto-completion, and live previews which makes coding 10x faster!
