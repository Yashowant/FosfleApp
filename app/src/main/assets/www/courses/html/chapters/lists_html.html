HTML lists allow web developers to group a set of related items. Learn how to organize your data into unordered bullets, ordered numbers, and dictionary-style descriptions.

Section 01

Unordered HTML Lists

An unordered list starts with the <ul> tag. Each list item starts with the <li> tag. The list items will be marked with bullets (small black circles) by default.

ExampleHTML
<h3>Grocery List</h3>
<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
Browser Output

Grocery List

  • Coffee
  • Tea
  • Milk
Section 02

Ordered HTML Lists

An ordered list starts with the <ol> tag. Each list item still uses the <li> tag. The list items will be marked with numbers by default, which is perfect for step-by-step instructions.

ExampleHTML
<h3>Morning Routine</h3>
<ol>
  <li>Wake up</li>
  <li>Drink coffee</li>
  <li>Start coding</li>
</ol>
Browser Output

Morning Routine

  1. Wake up
  2. Drink coffee
  3. Start coding
Section 03

HTML Description Lists

HTML also supports description lists. A description list is a list of terms, with a description of each term. The <dl> tag defines the list, the <dt> tag defines the term (name), and the <dd> tag describes each term.

ExampleHTML
<dl>
  <dt>Coffee</dt>
  <dd>- Black hot drink</dd>
  
  <dt>Milk</dt>
  <dd>- White cold drink</dd>
</dl>
Browser Output
Coffee
- Black hot drink
Milk
- White cold drink
Section 04

Nested HTML Lists

Lists can be nested (list inside list). To nest a list, you must place the inner list entirely inside an <li> element of the parent list.

ExampleHTML
<ul>
  <li>Coffee</li>
  <li>Tea
    <ul>
      <li>Black tea</li>
      <li>Green tea</li>
    </ul>
  </li>
  <li>Milk</li>
</ul>
Browser Output
  • Coffee
  • Tea
    • Black tea
    • Green tea
  • Milk
🚫
Common Beginner Mistake Never place an inner list directly inside the <ul> or <ol> tags. It must be placed inside an <li> tag to maintain valid HTML structure!
Section 05

HTML List Reference & Attributes

A complete cheat sheet of all the available HTML tags and attributes you can use to construct and format your lists.

Core & Supplementary Elements

Tag Description
<ul> Defines an unordered (bulleted) list.
<ol> Defines an ordered (numbered/lettered) list.
<li> Defines an individual item inside an ordered or unordered list.
<dl> Defines a description list wrapper.
<dt> Defines a term/name inside a description list.
<dd> Defines the description or value for the preceding term.
<menu> An alternative to <ul> used semantically for interactive toolbars, menus, or lists of command triggers.
<dir> Deprecated
Obsolete in HTML5. Previously used for directory lists; use <ul> instead.

HTML List Attributes Reference

Tag Attribute Allowed Values Description
<ol> type 1, a, A, i, I Sets the markers to numbers, letters, or Roman numerals.
<ol> start Number (e.g., 5) Specifies the starting value of an ordered list.
<ol> reversed None (Boolean) Reverses the list numbering from high to low.
<li> value Number (e.g., 10) Forces the specific item (and following items) to a custom number inside an ordered list.
Chapter Summary

Everything that stuck to the catalog

Use the HTML <ul> element to define an unordered list (bullets).

Use the HTML <ol> element to define an ordered list (numbers or letters).

Use the HTML <li> element to define a single list item within either of the above lists.

Use the HTML <dl>, <dt>, and <dd> elements to define a description list.

Lists can be nested inside one another by placing a new list inside an existing <li>.

Modify list behavior using attributes like type, start, reversed, and value.
