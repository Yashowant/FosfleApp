HTML Elements

An HTML document is made up of HTML elements. In this chapter, we will break down the anatomy of an element, how to nest them inside each other, and the golden rules of writing clean HTML code.

1

What is an HTML Element?

An HTML element is defined by a start tag, some content, and an end tag.

<tagname> Content goes here... </tagname>

The HTML element is everything from the start tag to the end tag.

Start Tag Element Content End Tag
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<button> Click Me! </button>
<br> none (Empty Element) none
2

Nested HTML Elements

HTML elements can be nested (this means that elements can contain other elements). All HTML documents consist of nested HTML elements.

nesting.html 
<!DOCTYPE html>
<html>
<body>

  <h1>My First Heading</h1>
  <p>My first paragraph.</p>
  
  <div>
    <p>A paragraph inside a div!</p>
  </div>

</body>
</html>
Nesting Breakdown:
<html> element is the root element. It contains the entire document.
<body> element defines the document's body. It contains the <h1>, the first <p>, and the <div>.
<div> is a container element. It contains another <p> inside of it!
3

The HTML Family Tree

Because elements are nested inside one another, developers use family terms to describe their relationships. This is crucial for when you start styling with CSS or writing JavaScript!

Parents

An element that contains another element is the Parent. (e.g., The <body> is the parent of the <h1>).

Children

An element inside another element is a Child. (e.g., The <h1> is a child of the <body>).

Siblings

Elements that share the exact same parent are Siblings. (e.g., An <h1> and a <p> sitting next to each other).

4

Never Skip the End Tag!

Some HTML elements will display correctly even if you forget the end tag. For example:

<html>
<body>

<p>This is a paragraph
<p>This is a paragraph

</body>
</html>
However, never rely on this!

Unexpected results and extreme formatting errors can occur if you forget the end tag. Modern browsers try their best to "fix" your mistakes automatically, but relying on the browser to guess what you meant is a guaranteed way to break a complex website layout.

5

Empty HTML Elements

HTML elements with no content are called empty elements. Because they hold no text or children, they do not need a closing tag.

<br>

Creates a line break. Forces text to the next line without creating a new paragraph.

<hr>

Creates a horizontal rule. Draws a visible dividing line across the webpage.

<img>

Embeds an image. It uses attributes to point to the picture file.

6

HTML is Not Case Sensitive

HTML tags are not case sensitive: <P> means the exact same thing as <p>.

Best Practice: Always Use Lowercase

The HTML standard does not require lowercase tags, but the W3C (World Wide Web Consortium) recommends lowercase in HTML, and demands lowercase for stricter document types like XHTML. In the professional world, developers strictly write HTML tags in lowercase.

7

Sneak Peek: Attributes

If elements are the building blocks, Attributes are the settings. You place attributes inside the start tag to give the element extra powers (like telling an <a> tag where to link to). We will cover this next!

Reference Appendix

The Ultimate HTML Tag List

A complete cheat sheet of all standardized HTML elements, categorized by their structural and semantic purpose. Bookmark this page for your coding journey!

Document Metadata
  • <html> Defines the root of an HTML document.
  • <head> Contains metadata, machine-readable information, and scripts.
  • <title> Sets the document title displayed in the browser tab.
  • <base> Specifies the base URL for all relative URLs in a document.
  • <link> Links an external resource, usually a stylesheet, to the document.
  • <meta> Represents metadata that cannot be represented by other elements.
  • <style> Contains CSS styling information directly within the HTML.
Content Sectioning
  • <body> Represents the main visible content of the HTML document.
  • <article> Represents a self-contained, reusable composition like a blog post.
  • <section> Defines a generic standalone section of a document.
  • <nav> Groups a set of navigation links.
  • <aside> Marks content tangentially related to the content around it.
  • <h1> to <h6> Six levels of section headings.
  • <header> Groups introductory or navigational aids for a section.
  • <footer> Defines a footer for its nearest sectioning content.
  • <address> Indicates contact information for a person or organization.
Text Content
  • <p> Defines a paragraph block of text.
  • <hr> Represents a thematic break or horizontal rule separator.
  • <pre> Renders preformatted text exactly as written.
  • <blockquote> Indicates that the enclosed text is an extended quotation.
  • <ol> Defines a numbered, ordered list.
  • <ul> Defines a bulleted, unordered list.
  • <li> Declares a single list item.
  • <dl> Represents a description list enclosing terms and descriptions.
  • <dt> Specifies a term/name in a description list.
  • <dd> Provides the description for the preceding term.
  • <figure> Encapsulates self-contained content, often with a caption.
  • <figcaption> Provides a text caption for a figure element.
  • <div> Serves as a generic block-level container for styling or layout.
  • <main> Encapsulates the dominant, central content of the document.
Inline Text Semantics
  • <a> Creates a hyperlink to web pages, files, or locations.
  • <em> Marks text that has emphatic stress (italics).
  • <strong> Marks text with strong importance (bold).
  • <small> Represents side-comments and small print.
  • <s> Renders text with a strikethrough.
  • <q> Indicates a short, inline text quotation.
  • <code> Displays a brief fragment of computer code.
  • <span> Acts as a generic inline container for phrasing content.
  • <br> Produces a line break (carriage-return) in text.
  • <u> Renders text with an unarticulated inline underline.
  • <mark> Highlights text for reference purposes.
  • <sub> / <sup> Subscript and Superscript text.
Table Content
  • <table> Renders multidimensional data into structural rows and columns.
  • <caption> Sets a descriptive title label for a table element.
  • <thead>, <tbody>, <tfoot> Encapsulates block headers, body, and summary rows.
  • <tr> Declares a horizontal row of cells within a table layout.
  • <th> Declares a header cell containing descriptor labels.
  • <td> Declares a standard, data-containing cell inside a table row.
Forms & Interactive Control
  • <form> Creates a section containing interactive controls to submit data.
  • <input> Generates a generic, highly customizable data-field input.
  • <button> Produces a clickable button behavior interface.
  • <select> & <option> Generates a dropdown menu control allowing value options.
  • <textarea> Renders a multi-line plain text editing field element.
  • <label> Defines a user-friendly caption label for a form control.
  • <details> & <summary> Creates an interactive disclose widget that reveals info on demand.
  • <dialog> Represents a modal or popup interactive dialog box.
Media, Embeds & Scripting
  • <img> Embeds an image file into the webpage.
  • <video> & <audio> Embeds media player capabilities supporting video/audio playback.
  • <iframe> Embeds another HTML document inside a nested window.
  • <script> Embeds executable client-side code, usually JavaScript.
  • <canvas> Provides a scriptable, drawable zone for graphics and animations.
  • <svg> Acts as a container for scalable vector graphics drawings.

Elements Conquered!
