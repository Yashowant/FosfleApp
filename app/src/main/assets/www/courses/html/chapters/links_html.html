Section 01

What are HTML Links?

HTML links are hyperlinks. You can click on a link and jump to another document, image, or website. When you move the mouse over a link, the mouse arrow usually turns into a little pointing hand.

Links are defined with the <a> tag, which stands for anchor.

💡
The href Attribute The most important attribute of the <a> element is the href attribute (Hypertext REFerence), which indicates the link's destination. Without it, the tag won't do anything!
Section 02

Syntax of a Link

A basic link has three parts: the opening tag with the destination, the clickable text (or image) inside, and the closing tag.

ExampleHTML
<a href="https://www.w3schools.com/">Visit W3Schools.com!</a>
Browser Output
Visit W3Schools.com!
Section 03

Absolute vs. Relative URLs

The destination you put inside the href attribute can point anywhere, but there are two main ways to write it:

Comparison of Absolute and Relative URLs
Type Description Example
Absolute URL A full web address. Used to link to other websites. Must include https://. href="https://google.com"
Relative URL A local link. Used to link to files within your own website. Does not include the domain name. href="about.html"
href="/images/logo.png"
⚠️
Don't forget the HTTPS! If you are linking to another website and forget to put https:// at the beginning, your browser will treat it as a relative link and try to find a file named "www.google.com" on your own computer.
Section 04

The Target Attribute

By default, linked pages will display in the current browser window (replacing the page you are currently on). To change this, you must specify another target for the link using the target attribute.

  • target="_self" : Default. Opens the document in the same window/tab as it was clicked.
  • target="_blank" : Opens the document in a new window or tab.
ExampleHTML
<a href="https://wikipedia.org/" target="_blank">
  Read more on Wikipedia
</a>
Browser Output
Read more on Wikipedia
Section 05

Special Link Types

Links don't just open web pages! By changing what you put inside the href attribute, you can trigger native applications on a user's device.

Email LinkHTML
<!-- Opens the default mail app -->
<a href="mailto:hello@example.com">
  Send us an email
</a>
Phone LinkHTML
<!-- Triggers a phone call on mobile -->
<a href="tel:+15555555555">
  Call +1 (555) 555-5555
</a>
Jump Link (Bookmarks)HTML
<!-- 1. Give an element an ID -->
<h2 id="chapter4">Chapter 4</h2>

<!-- 2. Link to that ID using a hashtag -->
<a href="#chapter4">Jump to Chapter 4</a>
