Phase 1: Tutorial Basics Introduction to HTML

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language for creating Web pages. It describes the structure of a webpage and tells the browser how content should be displayed.

The History of HTML

Who, When, and Why?

HTML was invented by a British computer scientist named Sir Tim Berners-Lee in 1989. At the time, he was working at CERN (the European Organization for Nuclear Research) in Switzerland.

Why was it made? Scientists at CERN were coming from all over the world, using different types of computers. Berners-Lee needed a universal way for them to share complex research documents and link them together easily. He combined the idea of Hypertext (clickable links jumping from one document to another) with Markup Languages (tags that format text) to create HTML.

The Evolution Timeline
1989 - 1991: The Birth

Tim Berners-Lee writes the first browser and server software. In 1991, he publishes a document called "HTML Tags," which outlined the first 18 elements of HTML (many of which we still use today!).

1995: HTML 2.0

The first formal standard for HTML was published, ensuring that different browsers (like early Netscape and Internet Explorer) could read the same code.

1999: HTML 4.01

A major milestone. This version standardized styling, tables, and scripts. It became the web standard for over a decade.

2014 - Present: HTML5

The modern era! HTML5 introduced native support for video and audio, semantic tags, and powerful APIs that allowed web pages to function like full-blown mobile applications.

Anatomy of an HTML Element

HTML is made up of elements. These elements enclose, or wrap, different parts of the content to make it appear a certain way.

1Opening Tag

Consists of the name of the element wrapped in opening and closing angle brackets. E.g., <p>

2Content

This is the actual text or material that is displayed on the screen. E.g., "Hello World!"

3Closing Tag

Exactly like the opening tag, but includes a forward slash before the element name. E.g., </p>

A Simple HTML Document

index.html 
<!DOCTYPE html>

<html>

<head>
    <title>Page Title</title>
</head>

<body>

    <h1>My First Heading</h1>
    <p>My first paragraph.</p>

</body>

</html>
