HTML Styles

The HTML style attribute is used to add styles to an element, such as color, font, size, and alignment. Let's learn how to make our boring black-and-white websites pop with design!

1

The HTML Style Attribute

Setting the style of an HTML element can be done with the style attribute. The HTML style attribute has a very specific syntax pattern.

<tagname style= "property:value;" >

The property is a CSS property. The value is a CSS value.

CSS Sneak Peek

By using the style attribute, you are actually writing inline CSS (Cascading Style Sheets). You will learn much more about CSS later in this tutorial, but for now, we will focus on applying it directly to our HTML tags.

2

Background Color

The CSS background-color property defines the background color for an HTML element. You can apply it to the whole page, or just specific elements.

background.html 
<!-- Setting the whole page background -->
<body style="background-color:powderblue;">

  <!-- Setting specific element backgrounds -->
  <h1 style="background-color:white;">This is a heading</h1>
  <p style="background-color:tomato;">This is a paragraph.</p>

</body>

3

Text Color

The CSS color property defines the text color for an HTML element.

<h1 style="color:blue;">This is a heading</h1>

<p style="color:red;">This is a paragraph.</p>

4

Fonts

The CSS font-family property defines the font to be used for an HTML element. Changing fonts is the fastest way to make a website look professional.

<h1 style="font-family:verdana;">This is a heading</h1>

<p style="font-family:courier;">This is a paragraph.</p>

5

Text Size

The CSS font-size property defines the text size for an HTML element. You can use pixels (px) or percentages (%).

<h1 style="font-size:300%;">This is a heading</h1>

<p style="font-size:160%;">This is a paragraph.</p>

6

Text Alignment

The CSS text-align property defines the horizontal text alignment for an HTML element. You can align text to the left (default), right, or center.

<h1 style="text-align:center;">Centered Heading</h1>

<p style="text-align:center;">Centered paragraph.</p>

7

Combining Styles

What if you want a heading that is centered, blue, AND uses the Verdana font? You can combine multiple CSS properties inside a single style attribute by separating them with a semicolon (;).

<h1 style="color: blue; text-align: center; font-family: verdana;">

</h1>

Borders & Rounded Corners

You can use the border property to draw a box around your HTML elements. You can even use border-radius to make the corners perfectly round!

<p style="border: 2px solid black;">
  Solid Border
</p>

<p style="border: 3px dashed blue;">
  Dashed Border
</p>

<p style="border: 2px solid red; border-radius: 15px;">
  Rounded Border
</p>

9

Spacing: Padding vs. Margin

One of the most confusing concepts for beginners is the difference between Padding and Margin. Padding creates space inside the border. Margin creates space outside the border.

Padding (Inside)

Notice how the text is pushed away from the blue border, creating a comfortable breathing room inside the box.

style="border: 2px solid blue; padding: 30px;"
I have lots of padding!

Margin (Outside)

Notice how the border wraps tightly to the text, but the entire box is pushed far away from the grey container wall.

style="border: 2px solid red; margin: 30px;"
I have lots of margin!
10

Adding Drop Shadows

You can easily add professional 3D depth to your elements using the box-shadow and text-shadow properties. This makes elements look like they are floating off the page!

<!-- Adding shadow to text -->
<h1 style="text-shadow: 2px 2px 5px red;">
  Glowing Text!
</h1>

<!-- Adding shadow to a box/image -->
<p style="box-shadow: 5px 5px 15px grey;">
  Floating Box!
</p>

11

Opacity & Transparency

The opacity property allows you to make any element (text, backgrounds, or images) partially transparent. The value ranges from 0.0 (completely invisible) to 1.0 (fully solid).

<img src="profile.jpg" style="opacity: 0.2;">
<img src="profile.jpg" style="opacity: 0.5;">
<img src="profile.jpg" style="opacity: 1.0;">
