HTML Text Formatting

HTML provides several formatting elements that help make text bold, italic, highlighted, important, deleted, inserted, smaller, subscript, and superscript. These tags improve readability and also give meaning to your content.

1

Introduction to HTML Formatting

Formatting tags are used to display text with special meaning. Some formatting tags only change the appearance, while others provide semantic meaning that browsers and screen readers can understand.

Did You Know? HTML formatting tags improve accessibility and SEO because they describe the importance of your content.
2

HTML Formatting Elements

HTML contains several built-in tags for formatting text.

  • <b> Bold Text
  • <strong> Important Text
  • <i> Italic Text
  • <em> Emphasized Text
  • <mark> Highlighted Text
  • <small> Smaller Text
  • <del> Deleted Text
  • <ins> Inserted Text
  • <sub> Subscript
  • <sup> Superscript
3

HTML <b> Element

The <b> element displays bold text without adding any extra importance.

Example 
<b>This text is bold</b>
Browser Output
This text is bold
4

HTML <strong> Element

The <strong> element defines text with strong importance. Browsers display it as bold. 

<strong>This text is important!</strong>
This text is important!
5

HTML <i> Element

The <i> element defines text in an alternate voice, mood, or style. It is usually displayed in italic. 

<i>This text is italic</i>
This text is italic
6

HTML <em> Element

The <em> element defines emphasized text. Screen readers pronounce emphasized text differently to indicate stress. 

<em>This text is emphasized</em>
This text is emphasized
7

HTML <small> Element

The <small> element defines smaller text. It is often used for copyright notices, legal information, or side notes.

Example 
<small>This is some smaller text.</small>
Browser Output
This is some smaller text.
8

HTML <mark> Element

The <mark> element highlights text just like using a yellow highlighter pen.

Example 
<p>
Do not forget to buy
<mark>milk</mark>
today.
</p>
Browser Output

Do not forget to buy milk today.

9

HTML <del> Element

The <del> element defines deleted text. Browsers usually display it with a line through it.

Example 
<p>
My favorite color is
<del>blue</del>
red.
</p>
Browser Output

My favorite color is blue red.

10

HTML <ins> Element

The <ins> element defines inserted text. Browsers usually underline inserted text.

Example 
<p>
My favorite color is
<del>blue</del>
<ins>red</ins>.
</p>
Browser Output

My favorite color is blue red.

11

HTML <sub> Element

The <sub> element defines subscript text. It appears slightly below the normal line and is commonly used in chemical formulas.

Example 
<p>
H<sub>2</sub>O
</p>
Browser Output

H2O

12

HTML <sup> Element

The <sup> element defines superscript text. It appears above the normal line and is commonly used for powers, exponents, and footnotes.

Example 
<p>
x<sup>2</sup>
</p>
Browser Output

x2

13

14

Important Differences

<b> vs <strong>

<b> makes text visually bold.

<strong> makes text bold and tells browsers and screen readers that the text is important.

<i> vs <em>

<i> only changes the appearance to italic.

<em> gives semantic emphasis, making it more meaningful for accessibility.

15

Best Practices

💡 Tips for Beginners
  • Use <strong> instead of <b> whenever the text is important.
  • Use <em> instead of <i> whenever you want to emphasize text.
  • Avoid using formatting tags only for decoration.
  • Use semantic HTML whenever possible.
  • Formatting tags improve accessibility and SEO.
