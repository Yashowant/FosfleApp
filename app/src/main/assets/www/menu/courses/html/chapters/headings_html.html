HTML Headings

Headings are the titles and subtitles that you want to display on a webpage. But they are far more than just "big text"—they are the absolute most important tags for Search Engines (like Google) to understand what your website is actually about!

1

The 6 Levels of Headings

HTML headings are defined with the <h1> to <h6> tags. <h1> defines the most important heading, while <h6> defines the least important heading.

2

Headings Are Important

Search engines use the headings to index the structure and content of your web pages. Users often skim a page by its headings. It is important to use headings to show the document structure!

For Search Engines (SEO)

Google's bots read your <h1> to figure out the main topic of your page. Then, they read your <h2> and <h3> tags to understand the sub-topics. If your structure is messy, your Google ranking will suffer.

For Accessibility (A11y)

Visually impaired users rely on "Screen Reader" software to browse the web. These programs use your heading tags to create an invisible "Table of Contents" so the user can easily jump between sections.

The Golden Rule of Headings

Never use HTML headings just to make text BIG or BOLD. Only use headings for document structure. If you just want to style regular text, use CSS instead.

3

Bigger Headings

Each HTML heading has a default size. However, you can specify the size for any heading with the style attribute, using the CSS font-size property:

<h1 style="font-size:60px;">Heading 1</h1>

HTML Horizontal Rules

The <hr> tag defines a thematic break in an HTML page, and is most often displayed as a horizontal rule (line). It is perfectly used to separate content (or define a change) alongside your headings.

<h1>This is heading 1</h1>
<p>This is some text.</p>
<hr>
<h2>This is heading 2</h2>
<p>This is some other text.</p>
<hr>

5

The Classic Beginner Confusion

Because HTML uses similar sounding words, beginners often confuse these three totally different tags. Let's clear this up once and for all!

<head>

Metadata Container. Lives invisibly at the top of your document. Holds the page title, CSS links, and scripts. The user NEVER sees this on the screen.

<header>

Layout Container. Used to build the visible navigation bar or top banner area of your website. Often holds your logo and navigation links.

<h1>

Text Element. This is just actual text! Specifically, the main title text displayed on the screen for the user to read.

6

The HTML5 Document Outline

In modern HTML, headings don't just float randomly. They are used inside semantic "sectioning" elements (like <article> and <section>) to create a perfect document outline.

outline.html 
<article>
  <h1>The History of Rome</h1>
  <p>Rome was founded in...</p>

  <section>
    <h2>The Roman Republic</h2>
    <p>The Republic began when...</p>
  </section>

  <section>
    <h2>The Roman Empire</h2>
    <p>The Empire began with...</p>
  </section>
</article>
Why do we do this?

By wrapping your <h2> tags inside of <section> tags, you explicitly tell the browser: "Everything inside this box belongs to this specific heading."

This makes styling with CSS significantly easier later on, and allows you to move entire chunks of content around your webpage without breaking the layout.

Common Heading Mistakes

When auditing beginner websites, professional developers frequently see the same two massive mistakes. Avoid these at all costs!

Mistake #1: Skipping Levels

Never jump from an <h1> directly to an <h3> or <h4> just because you prefer how the smaller text looks. This shatters the document outline.

<h1>My Website</h1>
<h4>Welcome!</h4> <-- WRONG!

Mistake #2: The <b> Substitute

Never use an <h5> or <h6> inside a standard paragraph just to make a word bold. Use <strong> or CSS for text emphasis instead.

<p>Please click <h5>Submit</h5> below.</p>
9

The "Multiple H1" SEO Debate

If you search online, you will find a massive debate among developers: "Can I use more than one <h1> tag on a single webpage?"

The Official HTML5 Spec

The specification says YES. If you use proper <article> and <section> tags, each section is technically allowed to have its own independent <h1> title.

The SEO Reality

Google's Webmaster tools state that while they can process multiple H1s, best practice is to use only ONE <h1> per page. It represents the main overarching topic, making your page much easier to rank.

Conclusion: Stick to ONE <h1> tag per page. It is safer, cleaner, and preferred by Search Engines!
