HTML Basic

Welcome to the core of the web! In this chapter, we will introduce the essential building blocks that make up almost every single webpage on the internet. Don't worry if you don't memorize them all immediately; we will use them constantly from here on out.

1

The HTML Skeleton

Every HTML document needs a basic structure to tell the browser what it is looking at. Think of this as the "skeleton" of your webpage.

skeleton.html 
<!DOCTYPE html>
<html>
<head>
  <title>Page Title</title>
</head>
<body>

  <h1>My First Heading</h1>
  <p>My first paragraph.</p>

</body>
</html>
Code Breakdown:
  • <!DOCTYPE html> Declares this document as HTML5.
  • <html> The root element that wraps all the content.
  • <head> Contains meta-information like the page title.
  • <body> Contains the visible content of the page (headings, text, images, etc).
2

HTML Headings

Headings are defined with the <h1> to <h6> tags. They are crucial for both users (readability) and search engines (SEO) to understand the structure of your page.

Heading Tags 
<h1>This is an H1 heading (Most Important)</h1>
<h2>This is an H2 heading</h2>
<h3>This is an H3 heading</h3>
<h4>This is an H4 heading</h4>
<h5>This is an H5 heading</h5>
<h6>This is an H6 heading</h6> <!--(Least Important)-->

SEO Pro Tip: Search engines use headings to index the structure and content of your web pages. You should strictly use only one <h1> tag per page for the main title, and use <h2> to <h6> to create a logical document outline. Never skip heading levels!

HTML Paragraphs

The <p> tag defines a paragraph. Browsers automatically add a single blank line before and after each paragraph.

<p>This is a paragraph. It contains text that represents a block of thought.</p>

<p>This is another paragraph. Notice how the browser will automatically separate them.</p>

Basic Text Formatting

You can easily make text stand out using formatting tags. The most common are <strong> for important bold text, and <em> for emphasized italic text.

<p>This text is normal, but this is <strong>important</strong>.</p>

<p>This text is normal, but this is <em>emphasized</em>.</p>

6

HTML Links

HTML links are defined with the <a> tag (which stands for "anchor"). The actual destination of the link is specified in the href attribute.

<a href="https://www.fosfle.netlify.app">Visit Fosfle Courses</a>
Anatomy of a Link:
  • <a>: The starting anchor tag.
  • href="...": The attribute storing the URL.
  • Visit Fosfle Courses: The clickable text the user sees.
  • </a>: The closing tag.

7

HTML Images

Images are defined with the <img> tag. The <img> tag is empty, meaning it contains attributes only, and does not have a closing tag.

<img src="profile.jpg" alt="A coding avatar" width="200">
Essential Image Attributes:
  • src: (Source) The path or URL to the image file.
  • alt: (Alternative text) Text displayed if the image fails to load. Critical for visually impaired users using screen readers!
  • width / height: Defines the size of the image in pixels. (Often controlled by CSS later).
Browser Preview

"profile.jpg"

What is an "Empty Element"? Unlike paragraphs (<p></p>) which wrap around text, an image tag doesn't wrap around anything. It just drops an image onto the page. Therefore, it doesn't need a closing </img> tag. Elements like this are called empty elements or void elements.
8

Peek Behind the Curtain

How to View HTML Source Code

Have you ever seen a webpage and wondered, "Hey, how did they do that?" You can actually read the HTML of any website on the internet!

View Page Source

Right-click on an empty space in any webpage and select "View Page Source" (in Chrome) or "View Source" (in Edge/Firefox). This will open a new window containing the raw HTML code of the page.

Inspect an HTML Element

Right-click on any specific image, button, or text and select "Inspect". This opens developer tools and shows you the exact HTML tag and CSS used to build that specific part of the page!
