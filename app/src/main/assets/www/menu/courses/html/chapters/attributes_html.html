HTML Attributes

HTML attributes provide additional information about HTML elements. In this chapter, we will master how attributes work, explore the most common use cases, and look at the essential properties that configure your webpage layout.

1

The Golden Rules of Attributes

Before writing them out, there are four absolute rules every developer must memorize about HTML attributes:

Extra Info

All HTML elements can have attributes to configure or modify their behavior.

Start Tag Only

Attributes are always specified inside the opening/start tag.

Name/Value Pairs

They usually come in name/value pairs like: name="value".

Quote Values

Attribute values should almost always be enclosed in double quotes.

2

The href Attribute

The <a> tag defines a hyperlink. The href attribute specifies the URL of the page the link goes to:

link.html 
<a href="https://fosfle.netlify.app">Visit Fosfle</a>
Live Link Output Visit Fosfle
3

The src, width, and height Attributes

The <img> tag embeds an image. The src attribute points to the file path, while width and height specify sizes in pixels:

<img src="img_girl.jpg" width="500" height="600">
Pro Tip: Always specify both width and height attributes for images. It reserves space on the screen for the image, preventing layout shifts while the page loads!
4

The alt Attribute

The required alt attribute specifies alternative text for an image if it cannot be displayed (due to slow internet, an error in the src, or if the user relies on a screen reader).

<img src="wrong_filename.jpg" alt="Girl with a jacket">
Simulated Broken Image Output
Girl with a jacket
5

The style Attribute

The style attribute is used to add inline styles to an element, such as color, font, size, and layout properties.

<p style="color:red; font-size:24px;">This is a stylized paragraph.</p>

This is a stylized paragraph.

6

The lang Attribute

You should always include the lang attribute inside the <html> tag to declare the default language of the webpage. This guides search engines and screen readers.

<html lang="en">
<body>
  ...
</body>
</html>

Country codes can also be appended: lang="en-US" configurations tell the engine it is American English.

7

The title Attribute

The title attribute adds extra information about an element. It is displayed as a small tooltip popup when a user hovers their mouse cursor over the element.

<p title="I am a generic tooltip description!">Hover over this text to see the tooltip.</p>

Hover over me!

8

Single or Double Quotes?

Double quotes around attribute values are the industry standard, but single quotes can be used. However, single quotes become mandatory if your attribute value itself contains double quotes inside it!

Example 1 (Single Outer)

<p title='John "Shotgun" Nelson'>

Example 2 (Double Outer)

<p title="John 'Shotgun' Nelson">

9

Boolean Attributes

Some attributes don't need a name="value" pair because their mere presence means True, and their absence means False. These are called Boolean attributes.

boolean.html 
<!-- This button is normal -->
<button>Submit Form</button>

<!-- The 'disabled' attribute locks the element -->
<button disabled>Cannot Click Me</button>

<!-- The 'checked' attribute pre-selects a checkbox -->
<input type="checkbox" checked>
Browser Output Preview
10

Global Attributes (id & class)

While some attributes only work on specific tags (like href on anchors), certain attributes can be used on **any HTML element** on earth. These are known as **Global Attributes**.

The class Attribute

Used to point to a specific style rule in a stylesheet (CSS). Multiple elements can share the exact same class identifier name.

<p class="error-text">Warning!</p>

The id Attribute

Specifies a completely unique ID for an HTML element. The ID value must never be duplicated on the same webpage document!

<div id="main-navigation">...</div>
11

The target Attribute

By default, when a user clicks an HTML link, it opens in the exact same tab. To force a link to open cleanly inside a brand new browser tab, pass the target="_blank" attribute configuration:

<a href="https://google.com" target="_blank">Open Google in New Tab</a>
Security Best Practice: When utilizing target="_blank", modern standards recommend attaching a secondary safety attribute called rel="noopener". This prevents the newly opened external page from maliciously hijacking or running performance-heavy processes on your original webpage tab!
12

Custom Data Attributes (data-*)

What if you want to store your own custom hidden information inside an element for a JavaScript app to read? HTML allows you to invent any attribute you want as long as it starts with the prefix data-.

metadata.html 
<!-- Storing a database product ID and category safely -->
<div class="shop-item" 
     data-product-id="98321" 
     data-category="shoes">
     Nike Air Sneakers
</div>
Why use data-attributes?

The user won't see data-product-id="98321" on the screen, but when they click the item, your backend code or Javascript analytics tools can instantly extract that specific number to add the correct shoe directly to their shopping cart database context!
