Not all information belongs in paragraphs. HTML tables allow web developers to arrange data into structured rows and columns.

Section 01

Defining an HTML Table

A table in HTML consists of table cells inside rows and columns. Tables are the best way to present data that needs to be easily compared and scanned, like a spreadsheet or a schedule.

ExampleHTML
<table>
  <tr>
    <th>Company</th>
    <th>Contact</th>
    <th>Country</th>
  </tr>
  <tr>
    <td>Alfreds Futterkiste</td>
    <td>Maria Anders</td>
    <td>Germany</td>
  </tr>
  <tr>
    <td>Centro comercial</td>
    <td>Francisco Chang</td>
    <td>Mexico</td>
  </tr>
</table>
Browser Output
Company Contact Country
Alfreds Futterkiste Maria Anders Germany
Centro comercial Francisco Chang Mexico
Section 02

Building Blocks: Rows, Cells & Headers

Tables are constructed using three primary elements: Rows (<tr>), Header Cells (<th>), and Data Cells (<td>). You can have as many rows as you like in a table; just make sure the number of cells is consistent across rows.

Data Cells<td>

td stands for table data. Everything between <td> and </td> is the content of a cell.

Note: A table cell can contain all sorts of HTML elements: text, images, lists, links, or even other tables!
Table Rows<tr>

tr stands for table row. Every row starts with a <tr> tag and ends with a </tr> tag.

<tr>
  <td>Emil</td>
  <td>Tobias</td>
</tr>
Table Headers<th>

th stands for table header. By default, the text in <th> elements is bold and centered.

<tr>
  <th>Person 1</th>
  <th>Person 2</th>
</tr>
Combined Output Example
Person 1 Person 2 Person 3
Emil Tobias Linus
16 14 10
Section 03

Semantic Grouping

For larger tables, group your rows into three distinct sections: <thead> (header), <tbody> (body content), and <tfoot> (footer/summaries). This keeps your HTML organized and helps browsers structure the layout better.

Full StructureHTML
<table>
  <thead>
    <tr>
      <th>Month</th>
      <th>Visitors</th>
    </tr>
  </thead>
  
  <tbody>
    <tr><td>June</td><td>1,400</td></tr>
    <tr><td>July</td><td>2,100</td></tr>
  </tbody>
  
  <tfoot>
    <tr>
      <th>Total</th>
      <td>3,500</td>
    </tr>
  </tfoot>
</table>
Section 04

Spanning Multiple Cells

Sometimes a row can have fewer or more cells than another because a piece of data belongs to multiple columns or rows. You can stretch a cell horizontally using colspan, or vertically using rowspan.

Colspan (Horizontal)

Stretches a cell across multiple columns. If a cell has colspan="2", it takes up the space of two cells, so you must write one less <td> in that row.

<td colspan="2">
<td>
<td>
<td>
<td>

Rowspan (Vertical)

Stretches a cell downward across multiple rows. If a cell has rowspan="2", it drops down into the next row, so the next row must contain one less <td>.

<td>
<td rowspan="2">
<td>
<td>
<td>
Example: Spanning in ActionHTML
<table>
  <tr>
    <!-- This cell stretches across 2 columns -->
    <th colspan="2">Employee Details</th>
  </tr>
  <tr>
    <td>Name:</td>
    <td>Alex</td>
  </tr>
</table>

Section 06

Accessibility & Best Practices

Tables are meant for tabular data, not for laying out your webpage (we use CSS Flexbox and Grid for that now). When building tables, ensure they are accessible to everyone, including users relying on screen readers.

🏷️
Use the <caption> tag It acts as a title for your table. It must be inserted immediately after the opening <table> tag. It helps users understand what data they are about to read.
🎯
Scope your headers Add the scope="col" attribute to column headers, and scope="row" to row headers. This explicitly tells screen readers which data cells belong to which headers.
<th scope="col">Price</th>
🚫
Never use tables for page layout In the late 90s, web developers used invisible tables to position images and sidebars. This is a terrible practice today. It destroys accessibility and breaks on mobile phones. Tables are for data only!
Section 07

HTML Table Tags Reference

A complete cheat sheet of all the available HTML tags you can use to construct and format your tables.

Tag Description
<table> Defines a table
<th> Defines a header cell in a table
<tr> Defines a row in a table
<td> Defines a cell in a table
<caption> Defines a table caption
<colgroup> Specifies a group of one or more columns in a table for formatting
<col> Specifies column properties for each column within a <colgroup> element
<thead> Groups the header content in a table
<tbody> Groups the body content in a table
<tfoot> Groups the footer content in a table
Chapter Summary

Everything that stuck to the ledger

The <table> tag creates the container. <tr> creates a row.

Use <td> for standard data cells, and <th> for header cells (which are bold and centered by default).

Table cells can contain regular text, as well as images, links, or lists.

Structure large tables using <thead>, <tbody>, and <tfoot>.

Use the colspan attribute to stretch a cell across columns, and rowspan to stretch it down rows.

Always use a <caption> and scope attributes to ensure your data is accessible to screen readers.
