Section 01

What is a Favicon?

A favicon (short for "favorite icon") is a small image displayed next to the page title in the browser tab. It is also used when a user saves your webpage as a bookmark or adds it to their mobile home screen.

Having a recognizable favicon is essential for branding and helps users quickly locate your website when they have dozens of tabs open.

💡
Size Matters Because favicons are displayed so small, they should be simple, high-contrast, and recognizable even at 16x16 pixels. Don't use complex photos or long words!
Section 02

How to Add a Favicon

To add a favicon to your website, you need to save an image file (like favicon.ico or logo.png) to your website folder and add a <link> tag inside the <head> section of your HTML document.

Example: index.htmlHTML
<!DOCTYPE html>
<html>
<head>
  <title>My Awesome Website</title>
  <!-- Favicon Link -->
  <link rel="icon" type="image/png" href="/images/favicon.png">
</head>
<body>
  <h1>Welcome to my website</h1>
</body>
</html>

⚠️
The Developer's Nightmare: Caching Browsers "remember" (cache) favicons very aggressively. If you change your favicon file but still see the old one, the browser is tricking you!

The Fix: Add a version parameter to the end of your file path, like this: href="/images/favicon.png?v=2". This forces the browser to download the new version.
Section 03

Supported Image Formats

Historically, all favicons had to be in the .ico format. Today, modern browsers support several different image formats for favicons.

Supported Favicon Image Formats
Format Type Attribute Notes
.ico type="image/x-icon" The classic format. Supported by every browser, even very old ones. Often used as a fallback.
.png type="image/png" The most popular format today. Supports beautiful transparency and high resolution.
.svg type="image/svg+xml" Vector graphics! Scales perfectly to any size without getting blurry. Supported by modern browsers.
🪄
Emojis as Favicons! Because modern browsers support SVG files, you can actually use a trick to set an Emoji as your favicon by putting the emoji inside an SVG data URL! Try it out in the Interactive Playground below.
Section 04

Modern Favicons & Generators

Today, a single 16x16 pixel favicon.ico isn't enough. Users might bookmark your website, add it to their iPhone home screen, or pin it on a Windows tablet. Different devices require different icon sizes and formats.

  • 16x16 & 32x32: Standard desktop browser tabs.
  • 180x180: Used for the Apple Touch Icon (when users save your site to an iOS device).
  • 192x192 & 512x512: Used in Web Manifests for Android devices.
